# Context layer

Durable facts about **you**. Agents load `00`–`05` before drafting, planning, briefing, or review. Run `set me up` to fill these; do not invent biography.

## Files

| File | Contains |
|---|---|
| `00-me.md` | Role, scope, Slack user id, how to address you |
| `01-working-style.md` | How you work, what "done" looks like |
| `02-portfolio.md` | Products and initiatives you own |
| `03-people.md` | Directs, leaders, partners |
| `04-goals.md` | Current-period goals |
| `05-glossary.md` | Personal vocabulary only — Phenom-wide terms belong in Product Copilot |
| `06-customers.md` | Accounts you personally own the relationship for |
| `99-open-questions.md` | Unresolved `[unconfirmed]` items |

## Markers

- No marker — you confirmed it.
- `[inferred]` — agent guess; never quote as fact.
- `[unconfirmed]` — asked, not answered.
- `@team` — true for any Phenom PM → promote to Product Copilot.
- `@personal` — stays here.
- `@sensitive` — never leaves. Performance, compensation, confidences, customer PII.

Default `@personal`. Nothing is written here without your yes in the session. No secrets.
