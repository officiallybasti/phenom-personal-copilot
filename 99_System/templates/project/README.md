# Project template

Copy this entire folder from `99_System/templates/project/` and rename it to your project name to start a new project (e.g. under `04_Projects/<project-name>/`).

## Folder structure

| Folder | Purpose |
|--------|---------|
| **meetings** | Notes, agendas, outcomes, follow-ups |
| **prototype** | Mockups, Figma links, clickable prototypes |
| **requirements** | PRDs, user stories, acceptance criteria |
| **background** | Context, discovery, problem space, research |
| **decisions** | Key product/tech decisions and rationale |
| **assets** | Screenshots, diagrams, reference images |
