# Optional: GSD / FIRE team board

Team weekly-goals audit is **not** part of the default personal OS.

If your org uses a shared Jira weekly-goals board, add a local rule and roster under this folder and load them only on `review GSD board`. Do not mix that loop with `plan my week`.

The reference implementation lives in a running personal vault, not in this template, so we do not ship someone else's roster or Jira account IDs.
